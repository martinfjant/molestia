## Sine Molestia ##
This is a collaborative work to translate and macronize the excellent but since long out of print Latin sans peine.

The translations (taken from Schola latinitatis universalis) can be found in /Translations, and at a Russian wiki page where a similar project is being done, the latin text can be found with macrons at http://linguaeterna.com/mediawiki/.

The files are combined into a nice little page using 11ty.

## Layout of lessons ##

Make the latin and english sentences numbered lists.

Make the footnote numbers small and rised using `<sup>Number</sup>`

Make the excersises numbered lists as well.

All headings except Lectio + number should be level 2.
